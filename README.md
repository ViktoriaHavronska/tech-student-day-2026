## 📌 Project Overview

**Tech Student Day 2026** is a 3-day student tech festival organized for 80–120 university students in Lublin, Poland. The event focuses on IT career exploration, networking, contests, and community building — helping students overcome uncertainty about their future in tech.

| Detail | Info |
|---|---|
| 📅 Dates | August 15–17, 2026 |
| 📍 Venue | HubSpace Coworking, ul. Narutowicza 38, Lublin |
| 👥 Attendees | 80–120 students |
| 💰 Budget | ~12,000 PLN (university-sponsored) |
| 🧑‍💼 PM | Junior Project Manager (me) |

---

## 🎯 Goals & Success Metrics

- Help students connect with IT professionals and peers
- Deliver 5 IT career talks across 3 parallel tracks
- Run team contests (quiz + mini-hackathon) with prizes
- Achieve NPS ≥ 8/10 and post-event survey response rate ≥ 60%

---

## 📅 3-Day Program

### Day 1 · Aug 15 — Open Day *"Welcome to the future"*
- Registration & welcome
- Icebreaker games (small teams)
- Keynote: *"Why now is the best time to be a student in tech"*
- Networking dinner

### Day 2 · Aug 16 — Main Day *"Explore & compete"*
- 5× IT Career Talks (parallel tracks)
- Team contests: quiz, mini-hackathon challenge, puzzle
- Games zone (board games, tech trivia)
- Prize ceremony + Panel discussion

### Day 3 · Aug 17 — Closing Day *"Celebrate & connect"*
- Retrospective workshop for participants
- Closing speeches + feedback forms
- Mini-concert (local student band / DJ)
- Free networking

## 🗂 Project Management Approach

This project is managed using **Scrum methodology** with 3 sprints.

### Tools Stack
| Tool | Purpose |
|---|---|
| **Jira** | Backlog management, Sprint planning, task tracking |
| **Miro** | Product Roadmap, Risk Register, Retrospective board |
| **Trello** | Day-of checklist for event execution |

### Backlog Structure
- **5 Epics:** Project Management · Venue & Logistics · Program & Content · Marketing · Event Execution
- **25 Stories** across 3 sprints
- **68 Story Points** total capacity
